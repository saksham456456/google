# Confession Website — Anonymous Sharing Platform 🤫

An anonymous, judgment-free platform for sharing confessions and connecting with others. A modern web application built with JavaScript focusing on community, privacy, and authentic human connection.

## 🎯 Overview

This is a full-featured confession sharing platform where users can anonymously share their thoughts, secrets, and confessions. Built with modern web technologies and designed with privacy and user safety as core principles.

## ✨ Key Features

- **Anonymous Posting** — Share without revealing identity
- **Community Engagement** — Upvote, comment, and support others
- **Real-Time Updates** — See new confessions instantly
- **Privacy-First Design** — No personal data collection
- **Content Moderation** — Safe community standards
- **Responsive UI** — Perfect on all devices
- **Dark Mode** — Comfortable viewing experience
- **Search & Filter** — Find relevant confessions easily

## 🚀 Getting Started

### Prerequisites
- Node.js 16+
- npm or yarn
- Modern web browser

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/saksham456456/google.git
   cd google
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure environment**
   ```bash
   cp .env.example .env.local
   ```

4. **Start development server**
   ```bash
   npm run dev
   ```

5. **Open in browser**
   - Navigate to `http://localhost:3000`
